# SDD Constitución

Define los principios innegociables del proyecto.

## Antes de proponer

Lee:
- `AGENTS.md`
- `MEMORY.md`
- código existente
- skill SDD

## Constitución

Crear o revisar:

`docs/constitucion.md`

Proponer como máximo 6 principios, cortos y verificables, cubriendo:

1. simplicidad del stack
2. relación entre spec y código
3. separación de lógica e interfaz
4. política de tests
5. protección de datos del usuario
6. idioma de código y textos

Máximo 15 líneas.

No modificar código.

La constitución debe contener principios verificables, no preferencias vagas.

## Respuesta

Indica:
- principios propuestos
- conflictos detectados con el proyecto actual
- qué debe aprobar el usuario
