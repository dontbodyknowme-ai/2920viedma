# MEMORY.md

## Contexto del Proyecto
- **Nombre:** Vinoteca High-End E-Commerce
- **Proposito:** Sitio web interactivo para una vinoteca de alta gama con catalogo de productos, carrito de compras, carga de articulos en tiempo real y navegacion con animaciones de scroll.
- **Estado Actual:** La aplicacion compila, arranca y funciona de punta a punta (catalogo, filtro por categoria, busqueda, carrito, carga de vinos, vista rapida y pie de pagina), con persistencia en `localStorage`. Verificado en navegador el 2026-10-06 con la spec `002-app-que-compile`.

## Decisiones de Arquitectura y Stack
- **Framework / Bundler:** React con Vite y TypeScript (soporta `npm run dev` y `npm test`).
- **Estilos:** Tailwind CSS con paleta personalizada en modo oscuro.
- **Animaciones:** Framer Motion (efectos parallax, revela al hacer scroll, animaciones del carrito y modales).
- **Gestion de Estado:** Hooks funcionales de React (`useState` y `useEffect`) en el componente raiz `src/App.tsx`. No se instalo ninguna libreria de estado externo: catalogo, carrito, busqueda y categoria activa viven en el orquestador y se pasan por props a los componentes. Si el estado crece y hay que compartirlo en profundidad, Context o Zustand siguen siendo opciones abiertas.
- **Escena 3D del hero:** `three` con `@react-three/fiber` y `@react-three/drei`, en `src/components/herocanvas3d.tsx`. El `<Canvas>` no se renderiza por debajo de 640 px de ancho de ventana: es la unica degradacion que RNF-09 define, y evita pedir WebGL donde no hay.
- **Almacenamiento de Datos:** `localStorage` para almacenamiento local en tiempo real del catalogo de productos y carrito.
